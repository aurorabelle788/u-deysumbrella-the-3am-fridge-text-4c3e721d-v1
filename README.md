One line, a text message a smart fridge sends its owner at 3am, for the [make.fun](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d) bounty.

## Run

```sh
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

This writes the entry line to `output/entry.txt`.
